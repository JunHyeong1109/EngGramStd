## Conventions
- **Branch naming:** each day's lesson is pushed to its own branch named `DayN` (e.g. `Day1`, `Day2`, `Day3`, ...) instead of the default session branch.
- **Branch scope:** each `DayN` branch contains only that day's lesson file (not previous days' files).
- **Language:** lesson explanations (topic intro, grammar notes) are written in Korean (한글). Example sentences stay in English with Korean translations.
- **This file (`PROGRESS.md` on `main`):** kept up to date after every day's lesson so a fresh session — regardless of which branch it's assigned — can find the current progress from `main`.

## Stage Map
- Days 1–15: Fundamentals — parts of speech, basic sentence structure, present/past/future tense, subject-verb agreement
- Days 16–30: Intermediate — modal verbs, conditional sentences, passive voice, relative clauses, articles
- Days 31–45: Advanced — subjunctive mood, complex sentence patterns, phrasal verbs, advanced tenses, stylistic grammar
